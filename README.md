## 📝 Descripción
Este repositorio contiene la resolución del Trabajo Práctico 2 correspondiente a la cátedra de Paradigmas de Programación de la carrera de Ingeniería en Sistemas (UTN FRM). El proyecto fue desarrollado íntegramente en Java y tiene como objetivo aplicar y afianzar los conceptos fundamentales de la Programación Orientada a Objetos (POO).

Entre los conceptos técnicos implementados en este sistema se destacan:
* Diseño de clases, encapsulamiento e instanciación de objetos.
* Aplicación de herencia y polimorfismo (sobrecarga y sobrescritura de métodos).
* Uso de clases abstractas e implementación de interfaces.
* Manejo y propagación de excepciones (`try-catch`, `throws`, y excepciones personalizadas).
## Tecnologías y Herramientas
* **Lenguaje:** Java (JDK [Tu versión, ej. 17])
* **Entorno de Desarrollo (IDE):** IntelliJ IDEA
* **Control de Versiones:** Git & GitHub

## Cómo abrir y ejecutar el proyecto localmente

### Opción 1: Clonar desde el IDE (Recomendado)
1. Copiar la URL de este repositorio: `https://github.com/serranonicolas1603-cloud/PP_TP2_53505`
2. Abrir **IntelliJ IDEA**.
3. En la pantalla de inicio, seleccionar **Get from VCS** (o ir a `File` -> `New` -> `Project from Version Control...`).
4. Pegar la URL en el recuadro de URL y hacer clic en **Clone**.
5. Esperar unos segundos a que el IDE indexe el proyecto y configure el JDK.
6. Buscar la clase que contiene el método `main` (por ejemplo, `Main.java` o `Sistema.java`), hacer clic derecho sobre ella y seleccionar **Run**.

### Opción 2: Descargando el archivo .ZIP
1. En la página principal de este repositorio, hacer clic en el botón verde **<> Code**.
2. Seleccionar la opción **Download ZIP**.
3. Descomprimir el archivo en tu computadora.
4. Abrir IntelliJ IDEA, ir a `File` -> `Open...` y buscar la carpeta que acabas de descomprimir.
5. Ejecutar la clase principal del sistema.
